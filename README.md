## 📚 Syllabus Covered

### PART A: COMBINATIONAL DESIGN
Combinational circuit woh hota hai jiska output sirf present input par depend karta hai. No memory.

| Sr. No | Practical Name | Aim |
|---|---|---|
| 1 | Study of Basic Logic Gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) | Truth table verification |
| 2 | Half Adder & Full Adder | Design using basic gates |
| 3 | Half Subtractor & Full Subtractor | Design using basic gates |
| 4 | 4:1 Multiplexer | Design & Truth Table |
| 5 | 1:4 Demultiplexer | Design & Truth Table |
| 6 | Encoder (8x3) & Decoder (3x8) | Design |
| 7 | K-Map Solver (2, 3, 4 Variable) | Minimization |
| 8 | Code Converters (Binary to Gray, Gray to Binary) | Conversion logic |

### PART B: SEQUENTIAL DESIGN
Sequential circuit me output present input + past memory (previous state) par depend karta hai.

| Sr. No | Practical Name | Flip-Flop Used |
|---|---|---|
| 9 | SR Flip-Flop | NOR/NAND based |
| 10 | JK Flip-Flop | Using SR Flip-Flop |
| 11 | D Flip-Flop | Using SR Flip-Flop |
| 12 | T Flip-Flop | Using JK Flip-Flop |
| 13 | SISO, SIPO, PISO, PIPO Shift Registers | D Flip-Flop |
| 14 | Asynchronous / Ripple Counter (4-bit) | JK Flip-Flop |
| 15 | Synchronous Counter (4-bit) | JK Flip-Flop |
| 16 | MOD-N Counter & Decade Counter | JK Flip-Flop |
| 17 | Ring Counter & Johnson Counter | D Flip-Flop |
